# 🚀 ElasTech Java + IA

Repositório dedicado às atividades, desafios e projetos desenvolvidos durante o programa **ElasTech**, da **SoulCode em parceria com o PagBank**, com foco em **Java + Inteligência Artificial**.

O objetivo deste repositório é registrar minha evolução prática ao longo da formação, desde os fundamentos da programação em Java até o desenvolvimento de aplicações e soluções envolvendo Inteligência Artificial.

---

## 📚 Conteúdos

### ☕ Fundamentos de Java

* Variáveis e tipos de dados
* Operadores
* Entrada de dados
* Strings e concatenação
* Estruturas condicionais
* Estruturas de repetição
* Arrays
* Métodos
* Programação Orientada a Objetos (POO)
* Classes e objetos
* Desafios práticos
* Lógica de programação

### 🔜 Próximos conteúdos

Conforme o avanço na formação, novos conteúdos, desafios e projetos serão adicionados ao repositório, incluindo temas relacionados a:

* Desenvolvimento Backend
* APIs REST
* Banco de dados
* Spring Boot
* Inteligência Artificial
* Integração entre Java e IA
* Projetos práticos
